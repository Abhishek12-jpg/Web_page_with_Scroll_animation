CHAPTER 03 · THE THREE-STEP PIPELINE

Precision at Every Byte.

Swift-native background daemon. Under 0.5% CPU.

STEP 01

Zero-Touch APFS Ingestion

Using native macOS FSEvents, dewDrive listens to file changes at the file-system level. It doesn't waste CPU indexing files that haven't touched a bit. Background consumption remains under 0.5% CPU.

STEP 02

Hardware Secure Enclave Chunker

Files are cut into semantic Rabin chunks, hashed using BLAKE3 at 1.4 GB/s NVMe wire speed, and encrypted in RAM using keys derived from Argon2id inside Apple Silicon's hardware Secure Enclave.

STEP 03

S3 Object Lock Dispatch

Deduplicated packfiles are streamed directly over authenticated TLS to your chosen storage destination with Compliance Mode Object Lock enabled, making historical snapshots completely ransomware-proof.
